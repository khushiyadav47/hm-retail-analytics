# H&M Retail Analytics

Customer intelligence case study on H&M's public Kaggle data (31.8M purchases). Independent portfolio project, not affiliated with H&M.

**Phase 1 (done):** data checks and cleaning. No duplicate customers or products, and every purchase links to a known customer and product.

**Next:** sales trends, customer value, churn, segmentation and recommendations.

**Tools:** DuckDB · SQL · Python · Parquet
